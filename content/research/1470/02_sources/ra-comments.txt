If you explore the game naturally and don't use a guide, you will not need very much grinding. I really recommended to not use a guide, also because it is much more rewarding to explore things on your own and figure them out, then to just follow a set of instructions that somebody else wrote.

For those completionist types, it is probably also a good thing that this game doesn't contain any of the medals or similar things they started adding in later games. 

The difficulty in the battles in the game aren't very hard until you reach the end of it, but the last part of the game is a little more challenging phase. But if you can figure out elementary resource management and strategy, it shouldn't be hard. 

There exists some enemies in this game which can kill your whole party if you are unlucky, but these enemies can only be found right after a savepoint, so you will never lose more than a few minutes of progress if you meet these. It isn't like some people claim where these enemies can ruin your whole run, because it is actually balanced in a sensible and reasonable way.

Overall, the game is not as good as DW3 and DW4, but it is a huge step up from DW1 and with some unique things about it which makes the game a lot of fun.
